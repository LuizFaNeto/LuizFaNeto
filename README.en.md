## 🚀 Featured project

### [Musicalizando](https://musicalizando-chi.vercel.app/)
Web app for managing private music lessons: daily agenda, monthly calendar,
student registration with fixed schedules, make-up lessons and attendance reports.

**Stack:** React + Vite + TypeScript · Lucide Icons · light/dark theme
**In progress:** migration from mocked data (localStorage) to Supabase (Postgres + Auth)

> Technical highlights: custom store with `useSyncExternalStore`, screen/component
> architecture with design tokens, and layout rules for `position:fixed` elements
> without `transform` (avoiding containing block issues in animations).
