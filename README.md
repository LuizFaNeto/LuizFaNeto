## 🚀 Projeto em destaque

### [Musicalizando](https://musicalizando-chi.vercel.app/)
Web app de gestão de aulas particulares: agenda do dia, calendário mensal,
cadastro de alunos com grade fixa, reposições e relatório de atendimentos.

**Stack:** React + Vite + TypeScript · Lucide Icons · tema claro/escuro
**Em evolução:** migração de dados mockados (localStorage) para Supabase (Postgres + Auth)

> Destaque técnico: store próprio com `useSyncExternalStore`, arquitetura em
> telas/componentes com tokens de tema, e regras de layout para elementos
> `position:fixed` sem `transform` (evitando containing block em animações).
